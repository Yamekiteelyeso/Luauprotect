# 🛡️ Lexy Protect v2.0 - Lua Obfuscator Suite

**Lexy Protect** es una plataforma web moderna e interactiva diseñada para la protección, cifrado y ofuscación de scripts en **Lua / Luau** (optimizada para Roblox y motores personalizados).

![Lexy Protect Banner](https://img.shields.io/badge/Lexy_Protect-v2.0-3b82f6?style=for-the-badge&logo=lua&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-emerald400?style=for-the-badge)

---

## ✨ Características Principales

- **Soporte Multi-Motor:** Integración con **Prometheus**, **Voltfuscator** y **Winfuscator**.
- **Ajustes de Presets:** Niveles `Low`, `Medium`, `High` y `Hardcore`.
- **Módulos Avanzados de Seguridad:**
  - 🔒 **Anti-Dump Protection:** Detección y bloqueo de volcados de memoria.
  - 👁️ **Anti-Spy:** Detección de interceptores de red y RemoteSpy.
  - 🐛 **Anti-Decompiler:** Crasher y sintaxis malformada contra descompiladores.
  - 🔀 **Control Flow Flattening (CFF):** Ofuscación de flujo de control.
  - 🔤 **Dynamic String Encryption:** Cifrado dinámico de cadenas de texto.
- **Terminal Interactivo en Tiempo Real:** Visualización de registros y estado de build.
- **Fallbacks Inteligentes:** Motor local de simulación cuando las APIs remotas están offline.
- **Diseño Moderno:** Tema *Dark Charcoal & Electric Blue Glassmorphism* responsivo.

## 🚀 Despliegue en GitHub Pages

1. Crea un repositorio en GitHub con el nombre `lexy-protect`.
2. Sube los archivos `index.html`, `styles.css`, `script.js`, `README.md` y `.gitignore`.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
5. Haz clic en **Save**. ¡Tu sitio estará en línea en un minuto!
